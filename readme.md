1. Если SSH слушает только 127.0.0.1:22, то подключиться к нему снаружи нельзя. Правило firewall только разрешает проход пакетов, но сам SSH всё равно должен быть доступен на внешнем IP-адресе.
2. Для выхода web42ns в интернет не хватает маршрута по умолчанию, включённого forwarding и NAT. Адрес 10.200.0.2 является внутренним и не может нормально использоваться в интернете. MASQUERADE заменяет его на внешний IP хоста.
3. Docker перенаправляет трафик с порта 8080 прямо в контейнер. Поэтому он проходит через PREROUTING и FORWARD, а не через INPUT. Из-за этого правило ufw deny 8080 не блокирует подключение к контейнеру.
4. При прямом открытии порта 8080 приложение становится доступно из интернета. При этом сложнее настроить HTTPS и направлять разные домены на разные приложения. При использовании nginx приложение остаётся внутри, а наружу доступен только nginx.
