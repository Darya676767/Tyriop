1. Да, прочитает, но `ls` не сработает. Бит `x` позволяет проходить в каталог и открывать файлы по известному имени, а бит `r` необходим именно для получения списка файлов.

2. Группа будет `alice`. Бит `setgid` работает только в том каталоге, где создаётся файл. Так как `/home/alice/` не имеет этого бита, копия получает основную группу создателя.

3. Минимизирует ущерб при взломе. `nologin` блокирует интерактивный вход, а одно правило `sudo` разрешает выполнить только одну конкретную команду. В группе `sudo` злоумышленник получил бы неограниченный root-доступ `sudo su`.

4. Нет, для webapp ничего не меняется владелец и так имеет полные права `rwx`. Опасность `777` только в третьей триаде (`others`): теперь любой пользователь системы может читать, изменять или удалять этот файл.
