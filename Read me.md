## Вопрос 4. Почему вирусов для Linux заметно меньше, чем для Windows, — дело только в популярности?
Linux изначально задуман как многопользовательская система — на одном компьютере (особенно сервере) работают десятки людей. Поэтому у каждого файла есть чёткие правила: кто может его читать, изменять и запускать. Права делятся на три действия — чтение (r), запись (w), выполнение (x) — и назначаются для трёх категорий: владельца файла, его группы и всех остальных. Это защищает файлы одного пользователя от чужих рук.Отдельно стоит суперпользователь root — administrator системы с неограниченными правами. Обычные пользователи работают с ограничениями, а чтобы временно получить права root для одной команды, используют sudo (буквально «сделай от имени суперпользователя»). Это ключевой элемент безопасности: даже если вредоносная программа запустилась под обычным пользователем, она не сможет тронуть системные файлы без пароля root. Именно поэтому вирусы на Linux встречаются реже — им сложнее получить нужные права.
